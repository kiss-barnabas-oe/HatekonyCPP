# Efficient C++ Assignments

Collection of C++ projects completed during the *Efficient C++* course, focusing on object-oriented programming, generic programming, memory management, and fundamental data structures.

## Projects

### Fraction Class

Implementation of a rational number type supporting arithmetic operations, comparisons, type conversions, parsing, and stream I/O.

**Highlights**

* Operator overloading
* Automatic fraction simplification using GCD
* Conversion operators (`int`, `double`, `bool`, `std::string`)
* Input/output stream support
* Exception handling and input validation

### Binary Search Tree

Generic binary search tree implementation using templates.

**Highlights**

* Template-based design
* Recursive insertion, search, and deletion
* Custom iterator implementation
* Copy and move semantics
* Dynamic memory management
* In-order traversal support
